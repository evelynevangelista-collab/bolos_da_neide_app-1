A cliente que solicitou o serviço da empresa MAX TECH SOLUTIONS LTDA, é a Dona Neide. Possui uma confeitaria, o qual não consegue administrar com plena organização e controle, devido a estes fatores a  contratante veio até nós solicitando um sistema web/desktop de gestão interna que registre pedidos para a confeitaria, em que focasse no cadastro das encomendas, exibisse alarmes/avisos de pedidos de última hora ou urgentes sobre uma interface simples e adaptada para a acessibilidade da cliente, contemplando tudo o que foi requisitado no contrato.
